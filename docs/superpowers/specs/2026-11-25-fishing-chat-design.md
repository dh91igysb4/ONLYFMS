# 펨타듀 밸리: 말풍선 채팅 설계 (승인됨, 2026-11-25)

온라인 2단계의 두 번째 조각. 사용자 결정: 기록 없이 말풍선만(A).

- 하단 "말" 버튼 → 입력칸(최대 40자) → Enter·보내기. 보낸 뒤 입력칸은 비우고 열어 둔다.
- 말은 앞뒤 공백을 다듬고 줄바꿈·연속 공백을 한 칸으로, 제어·방향 제어 문자를 뺀다(`show.ts` `cleanChat`). 비면 보내지 않는다.
- 3초에 한 번(`CHAT_GAP_MS`). 더 빠르면 보내지 않고 "잠시 뒤에 다시 말할 수 있어요".
- 이름 위 말풍선으로 5초(`CHAT_MS`). 새 말·이모트·자랑은 서로를 덮어쓴다(한 번에 하나).
- 전송은 자랑·이모트와 같은 플랫폼 `show` 칸: `c:<말>`(콜론을 담을 수 있어 앞 두 글자로만 가른다). 받는 쪽도 `cleanChat`으로 다시 정리·자른다.
- 기록·저장 없음, 그 자리에 없던 친구는 못 본다. 욕설 필터 없음(친구끼리). 글자는 `textContent`로만 넣는다.
- 입력칸에서 치는 동안 방향키·WASD·스페이스·M은 게임으로 가지 않는다(기존 입력칸 규칙). 서버·DB 변경 없음.
