# 펨타듀 낚시 — 큰 지도 설계 (2026-11-24)

상태: **초안** (사용자 결정 반영, 밤샘 작업 중 작성 — 아침 확인 대기)

앞선 설계: `2026-11-23-fishing-world-design.md`(넓은 세계, 특히 §5 어종·§8 지역·이동·도전과제·순간이동기). 이 문서는 그 위에 "버튼으로 여는 큰 지도"를 더한다. **4단계(도전과제·순간이동기)가 머지된 뒤에 만든다.** 4단계에 기대는 부분은 §7에 따로 모았다.

## 1. 의도

3단계까지 오면서 지역이 6곳, 낚시 자리가 11곳, 어종이 56종이 됐다. 지금 화면은 캐릭터 주변 몇 칸만 보여 주고, 도감은 잡은 물고기의 조건만 알려 준다. 그래서 두 가지 질문에 답할 곳이 없다.

1. **길찾기**: 여기가 어디고, 출구·다리·선착장·상점·순간이동기는 어디 있나? 섬은 어떻게 가나?
2. **잡을거리**: 지금 이 계절·시간·날씨에 내 낚싯대로 어디서 무엇이 잡히나? 아직 못 잡은 게 남은 곳은 어디인가?

사용자 결정(원문): "버튼으로 여는 큰 지도. 두가지 기능 다 필요해(길찾기+잡을거리). 레이어 띄우듯이, 필터 추가해도 좋을듯." 스포일러 수준은 **B**: 안 잡은 물고기는 실루엣과 등급만 보인다.

## 2. 목표 / 비목표 / 실패 조건

**목표**
- 하단 메뉴의 "지도" 버튼(데스크톱은 `M` 키도)으로 여는 지도 창. 지역 탭 6개, 처음엔 지금 있는 지역.
- 지역 맵 전체를 한눈에 보는 축소 그림 위에 표시(마커)를 얹는다.
- 레이어 2개: **길**(출구·잠긴 문·선착장·상점·순간이동기), **낚시 자리**. 현재 위치는 늘 보인다.
- 필터 2개: **지금 잡히는**(계절·시간·날씨·낚싯대·전설 잡음 여부), **미발견만**.
- 낚시 자리를 누르면 그 자리 물고기 목록: 잡은 물고기는 그림·이름·조건, 안 잡은 물고기는 실루엣 + 등급.
- 잠긴 지역은 탭에 잠김으로 보이고, 무엇을 얼마에 어디서 여는지 알려 준다.
- 다른 지역 탭에서는 그 지역까지 가는 길(지역 순서)을 보여 주고, 지금 지역 지도에서 첫 출구를 강조한다.
- 서버 변경 없음, `logic.version` 그대로. 화면만 바뀐다.

**비목표**
- 맵 안 칸 단위 길 안내선(캐릭터 → 출구 경로 그리기). 맵이 48×34 안팎이라 출구 표시로 충분하다.
- 확대·축소·끌어서 이동. 지도 한 장이 창 폭에 다 들어온다.
- 모든 지역을 이어 붙인 세계 전도. 세계 좌표(`world`)는 순간이동 요금 계산용이라 지도 배치용으로 맞춰져 있지 않다.
- 가 본 곳만 보이기(안개). 열린 지역은 처음부터 다 보인다.
- 도감 화면 변경(도감은 지금처럼 안 잡은 물고기를 `???`로 둔다).
- 지도 설정(레이어·필터)을 기기에 저장하기. 한 번 접속하는 동안만 기억한다.

**실패 조건 (동작해도 실패)**
- 지도에서 순간이동·해금 구매·배 타기가 된다. 지도는 정보만 준다(세계 설계 §3에서 "지도 메뉴 순간이동"을 버렸다).
- 안 잡은 물고기의 이름·그림·출현 조건이 지도 어디에서든 새어 나간다(`alt`·`aria-label` 포함).
- 지도가 "지금 잡힌다"고 했는데 서버 규칙으로는 그 물고기가 절대 안 걸린다(또는 그 반대).
- 지도에 찍힌 낚시 자리 표시로 걸어갔는데 거기서 그 자리 낚시가 안 된다.
- 지도를 열 때마다, 또는 시계가 흐를 때마다 맵 축소 그림을 다시 그려 폰이 버벅인다.
- 4단계 필드(순간이동기·도전과제)가 없거나 옛 응답이라 비어 있을 때 화면이 죽는다.
- 서버(`world` 함수)를 다시 배포해야 한다.

## 3. 제약

- 프로젝트 규칙 그대로: 화면 문구 한국어, 모바일 우선, 캔버스 밖 색은 `theme.css` 토큰만. 맵 축소 그림 안 색은 "낚시 캔버스 내부 색" 예외에 든다(만드는 곳이 캔버스다). 마커 그림은 `sprites.ts` 스프라이트를 `spriteDataUrl`로 쓴다(가방·도감의 물고기 그림과 같은 방식).
- 그림은 직접 그린 픽셀 아트만. 원작 지도 화면·아이콘을 베끼지 않는다.
- 계산은 전부 화면에서: 맵 정의(`maps/*.ts`), 어종(`data.ts`), 조건 판정(`speciesAvailable`), 시계(`clock.ts`, 서버 시각 보정 `offset`), 서버 view(`areas`·`dex`·`legends`·`rodTier`·`gold`, 4단계 뒤 `challenges`).
- 순수 계산(마커 자리, 낚시 자리 대표점, 물고기 목록·필터, 지역 경로)은 새 순수 모듈 `atlas.ts`에 둔다(React·DOM·`Date.now()` 없음, `.ts` import). 캔버스로 그림을 만드는 부분만 `minimap.ts`.
- 렌더 비용: 지역마다 축소 그림을 **처음 볼 때 한 번** 만들어 PNG 주소로 캐시한다. 만든 오프스크린 캔버스는 바로 크기 0으로 놓아 준다(iOS). 게임 화면을 떠나면 캐시를 비운다(`releaseSceneCache`와 같은 자리).
- 패널은 지금 메뉴처럼 캔버스 틀(`fish-frame`) 위에 덮는 `fish-panel`. 메뉴가 열리면 걷기 입력을 놓는 기존 규칙을 그대로 쓴다. 낚시 중(충전~싸움)에는 지도 버튼도 다른 메뉴처럼 막힌다.

## 4. 접근 방식

**지도 그림을 어떻게 만드나**
| | 방식 | 판단 |
|---|---|---|
| A | 장면 정적 캐시(16px 타일 그림 전체)를 줄여 쓴다 | 그림은 예쁘지만 맵 한 장 768×576px을 지역마다 새로 그려야 하고(장면 캐시는 현재 맵 하나뿐), 줄이면 16px 타일이 뭉개진다. 폰 메모리도 큼 |
| **B** | **칸마다 3×3px 무늬(타일 종류별 색 두 개)로 그린 축소 그림을 지역별 PNG로 캐시** | **선택.** 48×36칸 → 144×108px, 맵당 1,728번 칠하기(1ms 안팎). 정수 배로 키워 또렷하고, 색표가 `TileKind` 전체를 덮는지 타입·테스트로 지킨다 |
| C | 칸마다 HTML/SVG 요소 | 1,700개 요소가 폰에서 무겁고 색 토큰 규칙과도 맞지 않음 |

**표시(마커)를 어디에 그리나**
| | 방식 | 판단 |
|---|---|---|
| A | 축소 그림 캔버스 안에 같이 그린다 | 상태(잠김·필터)가 바뀔 때마다 다시 그려야 해 캐시가 깨지고, 누르기 판정·접근성 이름을 따로 짜야 함 |
| **B** | **그림은 `<img>`, 표시는 그 위에 퍼센트 좌표로 띄운 `<button>`** | **선택.** 그림 캐시는 진행과 무관(문 잠김도 표시가 맡음), 버튼이라 누르기·`aria-label`·jsdom 테스트가 그대로 됨. "레이어 띄우듯이"와 모양도 맞다 |

**물고기 정보를 어떻게 보이나**
| | 방식 | 판단 |
|---|---|---|
| A | 표시 옆 말풍선 | 폰에서 지도를 가리고 목록이 길면 넘침 |
| **B** | **지도 아래 상세 칸(패널이 세로로 스크롤)** | **선택.** 지도는 그대로 보이고, 자리 목록 칩이 작은 표시를 누르기 어려운 경우의 대안도 된다 |

## 5. 화면

### 5.1 배치 (폰 세로, 패널 폭 ≈ 300px 기준)

```
┌ 지도                                   [닫기] ┐
│ 봄 · 맑음 · 14:30 · 대나무 낚싯대              │  ← 지금 기준(1초마다 확인, 게임 1시간마다 다시 계산)
│ [바닷가 마을 9/16][마을 강 3/9][숲 2/8]          │
│ [산 호수 · 잠김][동굴 · 잠김][섬 · 잠김]  ← 가로 스크롤 탭
│ 보기  (길✓) (낚시 자리✓)                       │  ← 레이어 칩(누르면 켜고 끔)
│ 물고기 (지금 잡히는) (미발견만)                 │  ← 필터 칩
│ ┌────────────────────────────────┐ │
│ │  축소 그림(정수 배) + 표시 버튼들            │ │
│ │   ◎ 여기   ⇧ 출구   🔒 잠긴 문   ⛵ 배     │ │
│ │   🏠 상점   ✦ 순간이동기   ◇ 낚시 자리(숫자) │ │
│ └────────────────────────────────┘ │
│ 자리: [부두 3/6] [해안 6/10]          ← 자리 칩(표시와 같은 동작)
│ ── 상세 ──────────────────────────── │
│ 해안 · 지금 4종 · 미발견 2종                   │
│ [그림] 망둥어  지금  · 사계절                  │
│ [그림] 고등어  지금은 안 나와요(시간)          │
│ [실루엣] ???  드묾  지금                       │
│ [실루엣] ???  전설                             │
└──────────────────────────────────────┘
```
(위 그림의 기호는 설명용이다. 실제 표시는 직접 그린 9×9 픽셀 스프라이트.)

- 축소 그림 배율: `k = max(1, floor(패널 안쪽 폭 / (맵 칸 수 × 3)))`. 48칸 맵이면 패널 300px에서 k=2(288px, 칸당 6px), 데스크톱 넓은 창에서 k=3~4. 정수 배라 `image-rendering: pixelated`로 또렷하다.
- 표시 버튼은 누르기 영역 28px(그림 18px = 9×9 × 2). 위치는 `left = (tx + 0.5) / w × 100%`, `top = (ty + 0.5) / h × 100%`, 가운데 정렬.
- 지도 그림의 물 칸을 누르면 그 물의 낚시 자리를 고른다(`spotAtTile`). 표시가 작아 누르기 어려운 경우를 돕는다.
- 아무것도 고르지 않았을 때 상세 칸은 지역 요약: "물고기 16종 중 9종 찾음 · 지금 잡히는 7종", 자리 칩, 그리고 다른 지역 탭이면 가는 길(§5.5).

### 5.2 레이어와 필터

| 칩 | 기본 | 켜면 |
|---|---|---|
| 길 | 켬 | 출구·잠긴 문·선착장·상점·순간이동기 표시 |
| 낚시 자리 | 켬 | 자리 표시(숫자 배지)와 자리 칩 |
| 지금 잡히는 | 끔 | 배지·목록·탭 숫자가 "지금 잡히는" 물고기만 센다 |
| 미발견만 | 끔 | 배지·목록·탭 숫자가 아직 도감에 없는 물고기만 센다 |

- "현재 위치"는 칩과 무관하게 지금 지역 탭에서 늘 보인다(누를 수 없음, `aria-label="현재 위치"`, 보는 방향 표시).
- 배지·탭 숫자: 물고기 필터가 둘 다 꺼져 있으면 `찾음/전체`(예 `3/6`), 하나라도 켜져 있으면 필터를 통과한 수(예 `2`). 두 필터를 함께 켜면 "지금 잡을 수 있는 새 물고기"가 되고, 그 수가 0인 자리 표시는 흐리게(`opacity`) 보인다.
- 레이어·필터 상태는 Game이 들고 있어 창을 닫았다 열어도 유지된다(접속 동안만).

### 5.3 표시(마커) 종류와 상세

| 표시 | 자리 | 누르면 상세 |
|---|---|---|
| 현재 위치 | 캐릭터 칸 | (누를 수 없음) |
| 낚시 자리 | 자리 대표점(§6.2) | 자리 이름, 물고기 목록(§5.4), 그 자리 물·설 자리 칸 강조 그림 |
| 출구 | 가장자리 출구 범위의 가운데 칸 / 안쪽 출구 사각형 가운데 | "숲으로 가는 길 · 서쪽" + [숲 지도 보기] |
| 잠긴 문 | 문 칸 사각형 가운데 (잠긴 동안만) | "무너진 다리 수리 · 5,000 G · 보유 1,200 G · 다리 앞에서 열 수 있어요" |
| 선착장 | `dock.front` | 대상이 잠김: "배 · 50,000 G · 선착장에서 살 수 있어요" / 열림: "섬으로 가는 배 · 무료 왕복" |
| 상점 | 상점 문 앞 칸(`shopSpot`) | "상점 · 물고기 팔기, 낚싯대·가방·찌" |
| 순간이동기 | `map.teleporter` (4단계, §7) | 열림/잠김, 잠김이면 도전과제 제목·설명·진행도, 열림이고 지금 지역 이동기도 열려 있으면 "여기 이동기에서 오면 N G" |

- 안 연 지역으로 가는 출구에 같은 지역의 잠긴 문·선착장이 이 맵에 있으면 출구 표시는 숨긴다(문 표시가 대신한다. 강 북쪽 다리, 숲 동굴 입구가 이 경우).
- 문이 열린 뒤에는 문 표시가 사라지고 출구 표시가 나온다. 지도 창이 열린 채 해금될 일은 없지만(해금 창과 지도 창은 동시에 안 열린다) 계산은 매번 `view.areas`로 한다.
- 상세의 버튼은 "○○ 지도 보기"(탭 바꾸기) 하나뿐이다. 사기·타기·이동 버튼은 없다.

### 5.4 물고기 목록 (스포일러 B)

| | 잡은 물고기 | 안 잡은 물고기 |
|---|---|---|
| 그림 | `fish-<id>` | 실루엣(`{ silhouette: true }`) |
| 이름 | 이름 (+ 전설 표식) | `???` (전설은 도감처럼 테두리 표식) |
| 등급 | 등급 이름 | 등급 이름 — 흔함·드묾·희귀·전설 |
| 조건 | `conditionLabel` (도감과 같은 문구), 최대 크기 | 없음 |
| 지금 | "지금" 칩, 또는 "지금은 안 나와요 · 이유"(낚싯대/계절/시간/날씨/이미 잡은 전설) | "지금" 칩만(이유는 안 보임) |
| `alt` | 이름 | `미발견 물고기` |

- 정렬: 지금 잡히는 것 먼저, 그 안에서 등급(흔함→전설), 같은 등급은 `SPECIES` 순서.
- "지금"의 뜻은 "지금 던지면 걸릴 수 있다"이다. 등급 추첨 확률은 보여 주지 않는다. 전설의 던지기 힘 조건(`legend.power`)도 보지 않는다(서버 `speciesAvailable`과 같다).
- 이미 잡은 전설(`view.legends`)은 다시 안 나오므로 "지금"이 아니고 "세이브당 한 마리, 이미 잡았어요"로 보인다.
- 안 잡은 물고기에 "지금" 칩을 보이는 것은 사용자가 고른 "지금 잡히는 + 미발견만" 필터 조합이 어차피 알려 주는 정보라 B 수준 안이다. 조건 문구·필요한 낚싯대는 보이지 않는다.

### 5.5 잠긴 지역 탭과 가는 길

- 잠긴 지역 탭: 축소 그림 대신 잠김 카드 — "산 호수는 아직 못 가요 · 마을 강의 무너진 다리를 5,000 G에 고치면 열려요" + [마을 강 지도 보기](누르면 그 탭으로 가서 문 표시를 고른 상태). 아래에 그 지역 물고기 실루엣 목록(등급만, 필터 적용).
  - 어디서 여는지는 맵 정의에서 찾는다: 어느 맵의 `gates[].area` 또는 `docks[].target`이 그 지역인가(`unlockPlace`).
  - 지형을 숨기는 이유: 새 지역에 들어가 처음 보는 재미를 남긴다.
- 다른(열린) 지역 탭: 상세 맨 위에 "가는 길: 숲 → 마을 강 → 바닷가 마을 → (배) 섬". 열린 지역만 지나는 최단 경로(지역 칸 수 기준, `areaRoute`). 지금 지역 탭으로 돌아가면 그 경로의 첫 출구·선착장 표시를 강조(테두리)한다.
- 두 지역 모두 순간이동기가 열려 있으면 "순간이동기로도 갈 수 있어요"를 덧붙인다(4단계, §7).

### 5.6 열기·닫기

- 하단 메뉴: `가방 · 도감 · 지도 · 전체화면` (4단계가 메뉴 버튼을 더하면 그 뒤에 둔다). 좁은 폭(320px)에서 넘치면 `fish-menu`가 줄바꿈한다.
- 데스크톱 `M` 키(`e.code === 'KeyM'`, 한글 입력 상태에서도)로 열고 닫는다. 입력칸·다른 메뉴가 열려 있으면 무시, 낚시 중에도 무시.
- 열 때 탭은 지금 지역, 고른 표시는 없음. 닫기는 기존 `닫기` 버튼.
- 지도가 열려 있는 동안 게임 그리기 루프는 지금 메뉴들과 같이 그대로 돈다(바꾸지 않는다).

## 6. 계산 (전부 화면, `atlas.ts`)

### 6.1 표시 자리 `placeMarkers(map, opened)`
- 출구: 가장자리 출구는 그 가장자리 줄에서 `from..to` 가운데 칸(걷는 칸 중 가운데), 안쪽 출구는 사각형 가운데 칸. 방향은 `edge`(n/s/e/w → 북/남/동/서), 안쪽 출구는 "입구".
- 잠긴 문: 잠긴 동안만, 문 사각형 가운데 칸. 선착장: `front`. 상점: `shopSpot(map)`. 순간이동기: §7.
- 안 연 지역으로 가는 출구 중 같은 지역의 문·선착장이 같은 맵에 있으면 뺀다(§5.3).

### 6.2 낚시 자리 대표점 `spotAnchors(map, fixed)`
- 자리마다 "설 자리" = 걸을 수 있는 칸(모두 열린 상태 `ALL_AREAS_OPEN` 기준) 중, 네 방향 중 하나를 보면 `interactionAt`이 `{ kind: 'fish', spot }`을 주는 칸. 부두·해안 구분, 동굴 세 웅덩이, 숲 연못·폭포 모두 기존 `spotFor` 규칙에서 저절로 나온다.
- 대표점: 설 자리들의 무게중심에 가까운 순서로 보며, 이미 정한 표시(고정 표시 + 앞서 정한 자리)와 체비셰프 거리 `MARKER_GAP = 5`칸 이상 떨어진 첫 칸. 그런 칸이 없으면 무게중심에 가장 가까운 칸. 자리 순서는 `AREAS`의 `spots` 순서. 결정적이라 테스트로 고정한다.
- 맵은 바뀌지 않으므로 맵마다 한 번 계산해 모듈 안에 캐시한다(진행과 무관한 고정 표시만 `fixed`로 넘긴다: 출구·선착장·상점·순간이동기 자리. 잠긴 문은 열리면 사라지므로 넣지 않는다).
- 강조 그림용 `spotTiles(map, spot)`: 설 자리 칸 + 그 칸에서 보는 물 칸.
- 지도 그림 누르기용 `spotAtTile(map, tx, ty)`: 그 칸이 물이고 `map.spots`에 자리가 있으면 그 자리(부두 옆 바다는 `shore` — 부두는 표시·칩으로 고른다).

### 6.3 물고기 목록 `spotFish(area, spot, view, cond)` / `areaFish(area, view, cond)`
- 그 지역·자리 어종(`s.area === area && (!s.spots || s.spots.includes(spot))`).
- `found = !!view.dex[s.id]`, `legendDone = !!s.legend && view.legends.includes(s.id)`, `now = speciesAvailable(s, area, spot, cond, view.rodTier) && !legendDone`. 지역 전체 목록의 `now`는 그 지역 자리 중 하나라도 지금이면 참.
- 잡은 물고기의 "안 나오는 이유"는 `notNowReason`: 이미 잡은 전설 → 낚싯대 → 계절 → 시간 → 날씨 순으로 첫 번째.
- `cond = conditionsAt(Date.now() + offset)`. 패널은 1초마다 시계를 보고 `(gameDay, 시)` 또는 계절·날씨가 바뀔 때만 다시 계산한다(게임 1시간 = 실제 1분).

### 6.4 지역 경로 `areaRoute(from, to, opened)`
- 지역 그래프: 맵마다 `exits[].target`, `docks[].target`으로 이어짐. 대상이 열린 지역일 때만 지날 수 있다(`openExitAt`과 같은 규칙).
- 너비 우선 탐색으로 지역 수가 가장 적은 경로. 대상이 잠겼으면 경로는 그 지역을 여는 문·선착장이 있는 지역까지 + `unlockAt`.
- 순간이동기는 경로에 넣지 않는다(요금이 들고 도전과제가 필요). §5.5처럼 문구로만 알린다.

### 6.5 축소 그림 `minimap.ts`
- `MINIMAP_PX = 3`. 칸마다 3×3 무늬: 타일 종류별 `[바탕, 무늬]` 두 색과 무늬 모양(나무 = 가운데 진한 점과 십자, 바위 = 가운데 점, 꽃 = 한 점, 부두·선착장·다리 = 가로 판자 줄, 건물 = 지붕 위 줄, 문 = 가운데 어두운 칸, 물 종류는 무늬 없음). 색표는 `Record<TileKind, …>`라 새 타일을 넣으면 타입 오류가 난다.
- 동굴(`indoor`)은 바탕이 어두운 색이라 따로 손대지 않는다. 밤 색조·날씨는 지도에 넣지 않는다(정보 화면).
- `minimapUrl(map)`: 맵 id별 PNG 주소 캐시. 2D 컨텍스트가 없으면 `null`(그림 없이 토큰 바탕 위에 표시만 보인다 — jsdom·드문 기기).
- `spotHighlightUrl(map, spot)`: 그 자리 칸들을 반투명 밝은 색으로 칠한 투명 PNG, (맵, 자리)별 캐시. 고른 자리 위에 겹친다.
- `releaseMinimapCache()`: 캐시를 비운다. Game이 떠날 때 `releaseSceneCache`와 함께 부른다.

## 7. 4단계(도전과제·순간이동기)에 기대는 것

이 지도는 4단계 뒤에 만든다. 4단계가 들여올 것으로 **가정한 이름**은 아래와 같고, 다르면 빌더가 `atlas.ts`의 어댑터 함수 하나(`teleporterInfo`)와 `placeMarkers`의 순간이동기 줄만 고친다.

| 가정 | 이름·모양 | 지도에서 쓰는 곳 |
|---|---|---|
| 맵의 순간이동기 | `MapDef.teleporter: { tiles: Rect; front: TileFacing } \| null` (세계 설계 §8.1 "2×2칸 구조물과 그 앞 서는 자리") | 표시 자리 = `tiles` 가운데 칸(없으면 `front`) |
| 맵의 세계 원점 | `MapDef.world: { tx: number; ty: number }` | 직접 쓰지 않는다. 요금은 4단계의 요금 함수로만 얻는다(공식을 화면에 또 쓰면 서버와 어긋날 수 있다) |
| 도전과제 정의 | `data.ts` `CHALLENGES: readonly Challenge[]` (`{ id, area, title, desc, count, filter }`, 세계 설계 §8.3) | 잠긴 이동기 상세의 과제 제목·설명·목표 수 |
| 도전과제 진행 | `view.challenges: Record<string, { progress: number; seen?: string[]; done: boolean }>` (세계 설계 §9) | 이동기 열림 = 그 지역 과제 `done`, 진행도 `progress/count` |
| 순간이동 요금 | `teleportFee(from: AreaId, to: AreaId): number` (위치는 4단계가 정한 순수 모듈) | "여기 이동기에서 오면 N G" (두 이동기 모두 열림일 때만) |

**없을 때 (graceful absence)**
- `map.teleporter`가 없거나 `null` → 그 맵에 이동기 표시 없음.
- `view.challenges`가 없음(배포 사이 옛 응답) → 모든 이동기를 잠김으로, 진행도 0으로 본다(`view.tackles ?? []`와 같은 방식).
- 그 지역 과제가 `CHALLENGES`에 없음 → 상세에 과제 줄 없이 "잠김"만.
- 요금 함수가 없거나 지금 지역 이동기가 잠김 → 요금 줄을 뺀다.
- 4단계 "열린 이동기" 판정이 `done`이 아니라 다른 필드(예 `view.teleporters`)라면 `teleporterInfo` 안에서만 바꾼다.

4단계에 기대지 않는 부분(축소 그림, 길·낚시 자리 레이어, 필터, 물고기 목록, 잠긴 지역, 경로)은 4단계 없이도 동작하고 테스트할 수 있다. 계획의 Task 1~4는 4단계와 무관, Task 5만 4단계 이름을 쓴다.

## 8. 서버·배포

- 서버 상태·행동·`logic.version` 변경 없음. `world` 함수 재배포 불필요. Vercel 배포만.
- view에 새 필드를 요구하지 않는다(4단계 필드는 4단계가 이미 내보낸다).
- 배포 체크리스트에 수동 확인 항목을 더한다(계획 마지막 Task).

## 9. 내가 정한 것

사용자가 직접 정하지 않은 부분에서 내린 결정과 이유:

1. **지도 그림 = 칸당 3×3px 무늬 축소 그림, 지역별 PNG 캐시** — 장면 타일을 줄여 쓰는 것보다 싸고 또렷하다. 틀리면: 그림이 밋밋하다는 의견이 나오면 무늬만 손보면 된다.
2. **표시는 그림 위 HTML 버튼** — 캐시가 진행 상태와 무관해지고 접근성·테스트가 쉽다.
3. **잠긴 지역은 지형을 숨기고 잠김 카드(무엇·가격·어디서) + 물고기 실루엣** — 새 지역을 처음 보는 재미를 남기면서 목표(가격)는 분명히. 가격은 보여 준다(해금 창과 같은 값, `UNLOCKS`).
4. **지도에는 사기·타기·이동 버튼이 없다** — 세계 설계가 버린 "지도 순간이동"으로 미끄러지지 않게. 할 수 있는 건 탭 바꾸기뿐.
5. **"지금"은 서버와 같은 `speciesAvailable` + 이미 잡은 전설 제외, 전설 힘 조건·확률은 안 봄** — 서버 규칙과 어긋나지 않는 가장 단순한 뜻.
6. **안 잡은 물고기에도 "지금" 칩은 보이되 조건 문구·필요 낚싯대는 숨김** — 사용자가 원한 두 필터 조합이 어차피 드러내는 정보까지만.
7. **등급 이름: 흔함·드묾·희귀·전설** — 지금 화면에 등급 문구가 없어 새로 정함.
8. **배지 숫자: 필터 없으면 찾음/전체, 있으면 통과한 수** — 숫자 하나로 두 기능(수집 진도, 지금 갈 곳)을 다 보인다.
9. **길찾기는 지역 단위 경로 + 첫 출구 강조까지, 칸 단위 경로선은 안 그림** — 맵이 작아 출구만 알면 충분하고 구현이 크게 준다.
10. **`world` 원점은 직접 안 씀, 세계 전도 없음** — 요금 계산용 좌표라 배치가 지도에 맞지 않을 수 있다. 요금은 4단계 함수로만.
11. **순간이동기 상세에 "여기서 오면 N G"** — 섬처럼 비싼 이동을 계획할 때 쓸모. 두 이동기가 다 열렸을 때만.
12. **레이어 2개(길·낚시 자리) + 필터 2개(지금·미발견만), 기본은 앞의 둘만 켬** — 처음 열었을 때 길찾기와 자리 위치가 바로 보이고, 필터는 원할 때.
13. **설정은 접속 동안만 기억(기기 저장 없음)** — 저장 형식·이전 걱정 없이 시작. 원하면 나중에 localStorage.
14. **`M` 키로 열고 닫기** — WASD와 겹치지 않고 "Map"으로 외우기 쉽다.
15. **자리 대표점 간격 5칸, 겹치면 무게중심 가까운 칸** — 마을 부두와 해안처럼 가까운 자리가 겹치지 않게. 결정적이라 테스트로 고정.
16. **도감은 바꾸지 않음** — 도감은 안 잡은 물고기를 등급 없이 `???`로 두지만, 지도(B 수준)와 어긋나는 것을 맞추는 일은 이 작업 밖에 둔다.
17. **축소 그림 배율은 정수 배** — 3px 무늬가 고르게 커진다. 패널 안쪽 폭이 288px 이상이면 k=2(칸당 6px)가 나온다. 더 좁아 k=1(144px)이 되면 작지만 그대로 둔다(틀리면: 3px 대신 칸당 2px 무늬 + 정수 배로 바꾼다).
