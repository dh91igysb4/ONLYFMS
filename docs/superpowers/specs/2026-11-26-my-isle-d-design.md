# 내 섬 D단계 설계 — 바깥 꾸미기

작성 2026-11-26. 상위 설계 §2의 D("길·울타리·꽃·야외 가구를 칸마다, 나중에 밭"). C(`2026-11-26-my-isle-c-design.md`) 위에 쌓는다. 사용자가 맡기고 잠들어 결정 대부분은 **Claude가 정했다**(맨 아래 목록).

## 1. 왜
- 개간으로 넓힌 땅을 내 손으로 꾸민다. 친구가 놀러 와 "길 잘 깔았네"를 본다.
- C의 가구 놓기와 같은 손맛(만들기 → 놓기 → 치우기)을 섬 바깥으로.

## 2. 목표 · 비목표 · 실패 조건
**목표**
- 작업대 "꾸미기" 탭에서 바깥 꾸미기 10종을 만든다.
- 내 섬에서 아래 메뉴 "꾸미기"를 켜면, 앞 칸이 놓을 수 있는 땅이면 "놓기"(고르기 창), 놓인 꾸미기면 "치우기".
- 길·꽃밭은 밟고 지나가는 칸(땅 그림이 바뀐다), 나머지는 못 지나가는 물건.
- 친구 섬에서도 꾸민 모양이 보인다.

**비목표**
- 밭·작물(나중), 물건 돌리기, 2칸 이상 물건, 땅 높이·물 고치기.

**실패 조건**
- 꾸미기로 배에서 내리는 칸·선착장·집 문·작업대·자원 칸에 못 가게 되거나, 땅 일부가 끊긴다.
- 남이 내 섬을 바꾼다. 꾸미기로 골드가 생긴다. 옛 세이브(v24)를 읽지 못한다.

## 3. 접근
- **채택: C 가구와 같은 "보관함 + 놓인 목록" 방식을 섬에(내가 정함).** 섬 맵은 (모양, 개간, 집, 꾸미기)로 만든다. 놓기 규칙은 순수 함수 하나(`canDecorate`)를 서버·화면이 같이 쓴다.
- 버림: 칸마다 자유 그리기(타일 페인트) — 저장이 커지고 규칙 검사가 어렵다.

## 4. 상세
### 4.1 상태 (`State.isle`, logic.version +1)
```
decoBox: Record<DecoId, number>          // 0..99
deco: { id: DecoId; tx: number; ty: number }[]   // 최대 150
```
migrate: v24 섬은 비어 있음. 모르는 것·규칙 밖은 보관함으로.

### 4.2 꾸미기 10종 (내가 정함)
| id | 이름 | 밟기 | 재료·골드 |
|---|---|---|---|
| path | 돌길 | 지나감(길 그림) | 돌 2 · 100G |
| flowers | 꽃밭 | 지나감(꽃 그림) | 200G |
| fence | 울타리 | 막힘 | 나무 2 · 150G |
| bench | 벤치 | 막힘 | 나무 6 · 철 1 · 2,000G |
| lamp | 가로등 | 막힘 | 철 4 · 3,000G |
| mailbox | 우체통 | 막힘 | 나무 3 · 철 1 · 1,500G |
| pot | 큰 화분 | 막힘 | 돌 3 · 500G |
| flag | 깃발 | 막힘 | 나무 2 · 800G |
| statue | 석상 | 막힘 | 돌 20 · 15,000G |
| fountain | 분수 | 막힘 | 돌 30 · 철 10 · 30,000G |
- 최고 단계 원칙: 섬에 놓는 수 150개가 상한(골드 쓰는 곳이 끝없이 늘지 않게).

### 4.3 놓기 규칙 `canDecorate(shape, tx, ty, id)`
- 그 칸이 (개간·집 반영한) 섬 맵에서 걸을 수 있는 땅(모래·풀·길·꽃)이고 비어 있음.
- 배에서 내리는 칸·선착장(부두) 칸·집 문 앞·작업대 앞·고정물 앞이 아님. 건물 칸 아님.
- 막는 물건이면, 놓은 뒤에도 남은 모든 걸을 수 있는 땅이 배에서 내리는 칸에서 이어지고, 드러난 자원 칸마다 옆에 닿는 칸이 하나 이상 남는다.

### 4.4 행동
- `makeDeco { id, price }`, `decorate { id, tx, ty }`, `undecorate { tx, ty }`. 오류 `bad_deco`, `deco_full`, `no_deco`, `bad_spot`, `isle_full`(150), `no_deco_here`.

### 4.5 화면
- 작업대 탭 "꾸미기"(목록·가진 수·만들기).
- 아래 메뉴 "꾸미기" 버튼: 내 섬에서만 보인다. 켜면 앞 칸 판정이 놓기/치우기로 바뀐다(자원 칸·작업대 등 다른 행동은 그대로 우선).
- 꾸미기 고르기 창 "꾸미기 놓기". 놓으면 페이드 없이 맵만 바뀐다.
- 친구 섬: `publicView`에 `deco`. 기록 `deco`(놓은 수).

## 5. 제약
- C와 같다. 다른 세션이 낚시 버전을 또 올렸으면 리베이스하며 한 칸 더 올린다.

## 내가 정한 것 (사용자 확인 필요)
1. 꾸미기 10종과 값(§4.2), 섬에 150개 상한.
2. 길·꽃밭만 지나가고 나머지는 막힘. 돌리기 없음.
3. 꾸미기 모드 버튼(늘 켜 두면 섬 어디서나 행동 버튼이 "놓기"가 되어 거슬려서).
4. 밭은 이번에 하지 않는다.
