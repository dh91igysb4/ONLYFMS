# 펨타듀 밸리: 물고기 자랑·이모트·버리기 설계 (승인됨, 2026-11-25)

온라인 2단계의 첫 조각. 말풍선 채팅과 대전 걸기는 다음 PR들에서 따로 한다(사용자 결정).

## 물고기 자랑
- 가방 위 누르기 모드 셋: **잠금**(기본, 지금처럼) / **자랑하기** / **버리기**.
- 자랑하기 모드에서 물고기를 누르면 가방이 닫히고 6초 동안 캐릭터가 그 물고기를 머리 위로 든다(잡았을 때 그림 재사용).
  이름표가 보이고 그 아래 카드 한 줄: `참돔 62cm · 1,240 G · 희귀`(전설·신화는 강조 색). 걷거나 던지면 바로 끝난다.
- 가격은 버프를 뺀 기본 판매가(`price`: 크기·퍼펙트만). 받는 쪽도 같은 데이터로 계산한다.
- 값은 보낸 쪽을 믿는다(사용자 결정, 위치와 같은 신뢰 수준). 받는 쪽은 모르는 어종·크기 범위 밖·잘못된 모양이면 무시한다.

## 이모트
- 하단 메뉴 "이모트" → 👍 😂 😮 😭 ❤️ 🎣 중 하나를 누르면 3초 동안 머리 위에 뜬다. 낚시 중에도 된다.

## 전송
- 플랫폼 위치 메시지(`pos`)에 게임이 해석하는 짧은 문자열 `show`(128자 이하, 선택)를 더한다. 플랫폼은 내용을 모른다(게임별 분기 없음).
  `show`가 바뀌면 다음 보낼 차례(움직임 간격)에 바로 보내고, 멈춰 있어도 2.5초마다 다시 보내므로 자랑 중 들어온 친구도 곧 본다.
- 낚시 형식: 자랑 `b:<어종>:<cm>:<0|1>`, 이모트 `e:<id>`.
- 친구가 없어도 내 화면에는 보인다. 서버·DB 변경 없음.

## 버리기
- 버리기 모드에서 물고기를 누르면 확인 줄 `망둥어 12cm 버리기 · 환경부담금 3 G` → 버리기.
- 환경부담금 = `max(1, ceil(sellPrice(물고기, 버프) / 10))`(감쇠 전 판매가의 10%, 올림, 최소 1 G, 사용자 결정 A). 파는 쪽이 늘 낫다.
- 잠긴 물고기는 버릴 수 없다(`locked`). 골드가 모자라면 `not_enough_gold`. 어디서나 버릴 수 있고, 오늘 판 마릿수에 들지 않는다.
- 서버 행동 `{ type: 'discard', index, fee, species, sizeCm }`: `fee`는 화면이 본 부담금(다르면 `price_changed`), 어종·크기가 그 칸과 다르면 `bag_changed`(다른 탭·응답 유실로 칸이 밀렸을 때 다른 물고기를 버리지 않게). 낚시 `logic.version` 16.
- 잡은 직후 결과가 떠 있을 때도 자랑할 수 있다(던지기·낚시 중·걷기·지역 이동·얼음 뚫기에서 끝난다).

## 메모
- 잠금으로 비싼 물고기만 먼저 팔아 100% 구간을 쓰는 것은 의도한 동작이다(사용자, 2026-11-25). 가방 칸이 상한이다.
