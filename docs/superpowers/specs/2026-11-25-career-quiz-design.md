# 커리어 퀴즈 설계

선수의 1군 클럽 경력을 보고 누구인지 맞히는 게임. 데이터는 `data/football/`(위키데이터 수집, 설계 `2026-11-01-football-data-layer-design.md`)를 쓴다.

- 게임 id: `career-quiz`, 이름: 커리어 퀴즈
- 모드: 자유 플레이만(`modes: { daily: false, contest: false, free: true }`). 데일리는 나중에 다시 본다.
- 출제: 현역·은퇴를 가리지 않는다. 문제 명단은 §4.

## 1. 선택지 (manifest `options`)

| key | 값 | 기본 |
|---|---|---|
| `mode` | `normal` 일반 / `challenge` 챌린지 | `normal` |
| `tier` | `easy` 쉬움 / `normal` 보통 / `hard` 어려움 | `easy` |

## 2. 진행

공통:

- 기회는 8번이다. 선수를 답하거나 줄을 열 때마다 하나씩 쓴다.
- 답은 전체 선수 DB에서 검색해 고른다(§5).
- 이니셜 힌트: 선수를 3번 이상 답한 뒤(줄 열기는 세지 않음) 한 번 쓸 수 있다. 영문 이름의 첫 글자를 보여 준다(`L. M.`, 후알야 `initialsOf`와 같은 규칙). 기회는 쓰지 않는다.
- 맞히거나, 8번을 다 쓰거나, 포기하면 끝난다. 끝나면 정답과 전체 경력을 보여 준다.

### 2.1 일반 모드

- 경력 전체를 처음부터 보여 준다. 한 줄은 연도와 클럽(임대 표시)이고, 경기·골 수는 보여 주지 않는다.

### 2.2 챌린지 모드

- 처음에는 첫 줄(데뷔 클럽)만 열려 있다. 나머지 줄은 연도만 보이고 클럽은 가린다(`2009–2013 ■■■`).
- 다음 줄이 열리는 경우는 두 가지다.
  - 답이 틀렸을 때 자동으로 열린다.
  - "한 줄 열기" 버튼을 누르면 기회를 하나 쓰고 열린다.
- 모든 줄이 열린 뒤에는 틀려도 기회만 준다. 버튼은 사라진다.
- 가린 줄의 클럽은 `publicState`에 넣지 않는다. 연도만 보낸다.

### 2.3 경력 줄 (1군 프로 무대만)

`spells.csv`에서 다음 구간을 뺀다.

1. **2·3군 팀**: 팀 이름 규칙(` B`, ` C`, ` II`, `Castilla`, `Atlètic`, `Jong `, `U-19`, `Primavera`, `Reserves` 등)과 직접 명단 `manual/reserve_teams.csv`(`team_id,note`)로 거른다. 이름 규칙에 잘못 걸리는 1군 팀(Willem II 등)은 명단 `manual/first_teams.csv`로 살린다.
2. **유스 구간**: 경기 수가 비어 있고 만 18세 생일 전에 끝난 구간(호날두의 안도리냐·나시오날).
3. **직접 지정**: 위 규칙이 틀리는 경우는 `manual/career_quiz_hide.csv`(`source_ref,note`)로 뺀다.

표기: 선수·클럽 이름은 영문(`name_en`)으로 통일한다. 클럽은 짧은 이름(`Chelsea F.C.` → `Chelsea`, `FC Bayern Munich` → `Bayern Munich`)으로, 앞뒤 법인·종목 약어와 창단 연도를 떼는 규칙(`shortClubName`)과 직접 지정 `manual/career_quiz_club_names.csv`(`team_id,name`: Real Madrid, AC Milan, Marseille, Lyon, Flamengo, LAFC, 겹치는 이름 Vitória Guimarães·Vitória Setúbal 등)로 만든다(사용자 결정 2026-11-26. 한글 표기가 위키데이터 라벨마다 제각각이라). 정답·답한 선수·검색 후보도 영문이고, 검색은 한글 별칭으로도 된다. 버튼·안내 문구와 "임대" 표시는 화면 문구라 한국어다(CLAUDE.md).

정렬은 시작 연도, 끝 연도 순이다. 한 줄은 `시작–끝 클럽 (임대)`이고, 끝 연도가 없으면 `시작–`이다. 거른 뒤에도 1군 경력이 한 줄 이상 있어야 문제가 된다(데이터 검사, §7).

## 3. 점수 (0~10)

| | 맞혔을 때 | 못 맞히면 |
|---|---|---|
| 일반 | `11 − 쓴 기회` (첫 번에 10점, 8번째에 3점) | 0 |
| 챌린지 | `11 − 열린 줄 수` (첫 줄만 보고 10점), 최저 1 | 0 |

- 이니셜 힌트를 썼으면 3점을 빼고, 최저 1점이다(후알야 `HINT_PENALTY`와 같다).
- 동점 처리(`actionCount`)는 쓴 기회 수다.
- 골드는 자유 플레이 골드 규칙(CLAUDE.md, 지갑 설계 §7.3)에 맞춰 `gold.test.ts`로 정한다.

## 4. 문제 명단

`data/football/manual/career_quiz.csv` (`player_id,tier,name`), 375명. 쉬움 76명, 보통 142명, 어려움 157명.

고른 기준(2026-11-25, main `908c232` 데이터):

1. 널리 알려진 선수: 발롱도르 후보 명단(`manual/legends.csv`)과 인지도(`popularity`) 97 이상에서 사람이 골랐다. 인지도는 위키 문서 수 백분위라 99~100에 몰리고, 일본 선수가 높게 나온다. 그래서 숫자로 자르지 않았다. 한국 선수(손흥민, 박지성, 김민재, 황희찬, 이강인, 기성용, 이청용, 황의조, 설기현)는 일부러 넣었다.
2. 너무 어리지 않은 선수: 첫 프로 경력이 2018년 이전이다.
3. 클럽 수 제한 없음: 처음 명단은 3곳 이상으로 골랐다. 뒤에 사용자 결정으로 두 곳(비니시우스·차비·카시야스·제라드·노이어·뮐러 등)과 원클럽맨(토티·말디니·긱스·푸욜·포든·사카 등)도 넣었다. 원클럽맨은 챌린지에서 첫 줄이 곧 전체 경력이다.
4. 경력 전체(클럽과 시작 연도의 순서)가 같은 다른 선수가 DB에 없다(인지도 50 이상 선수끼리 본다. 사카와 같은 경력으로 잡힌 인지도 28의 여자 선수처럼 낮은 쪽은 데이터 오류가 많다).

난이도는 사람이 매겼다. 대략 쉬움은 지금 세대 슈퍼스타와 한국 선수, 보통은 2000~2010년대 주전급, 어려움은 덜 알려졌거나 경력이 헷갈리는 선수다. 명단은 후알야 `EASY_IN/OUT`처럼 리뷰하며 고친다.

### 4.1 데이터 손본 것

- 2·3군을 빼니 1군 클럽이 2곳뿐인 비니시우스(카스티야), 차비, 카시야스를 한때 빼고 래시퍼드(쉬움), 로이스·호르디 알바(보통)를 넣었다. 뒤에 최소 기준을 2곳으로 낮춰 세 명을 다시 넣었다. 그 뒤 원클럽맨과 빠졌던 유명 선수 64명(267명), 다시 현역·은퇴 유명 선수 61명(밀너, 사네, 구보, 황인범, 바레시, 데샹, 박주영, 이동국 등)을 더 넣었다(328명). 그 뒤 다빈손 산체스와, 위키데이터 소속 날짜가 없어 빠졌다가 경력을 직접 조사해 넣은 선수 중 46명(클라위버르트, 아쿠냐, 라스파도리, 말라시아, 아우아르, 이토 히로키, 세코 아유무, 질마르, 루이스 페르난데스 등)을 더 넣었다(375명). 프렝키 더 용은 빌럼 II가 이름 규칙(` II`)에 걸려서 `manual/career_quiz_first_teams.csv`로 살렸다.
- 한글 이름이 공식 전체 이름이던 선수(하피냐, 마르키뉴스, 줄리우 세자르, 아드리아누, 마이콩, 하비에르 에르난데스, 페드로, 윌리안, 루이스 수아레스, 디에고 코스타)와 한글 이름이 없던 나니를 `manual/names_ko.csv`에 넣고 `players.csv`에도 반영했다(다음 수집도 같은 값을 쓴다). 운영 DB 검색에 보이려면 `football:load`를 다시 돌린다.
- 부스케츠: 위키데이터의 바르셀로나 경력이 유스 포함 2000년부터라, 구단 공식 기사(1군 데뷔 2008-09-13)를 근거로 `manual/spells.csv`에서 2008년으로 고쳤다.
- 한글 이름이 없던 클럽 44곳(웨아의 라이베리아 클럽 등)을 `manual/names_ko.csv`에 넣고 `teams.csv`에도 반영했다. PAOK·FCSB는 약칭 그대로 둔다.
- 프랑스 비치사커 국가대표(칸토나)와 FC 제니트-2(2군)는 `manual/career_quiz_reserve_teams.csv`로 뺐다.
- 주앙 펠릭스: 위키데이터가 2024-25 첼시를 Corvinul Hunedoara로, 2025 알나스르 이적을 수단 알힐랄로 잘못 갖고 있어 `manual/spells.csv`로 두 구간을 지우고 첼시(2024-08-21~2025-07-29, 첼시 공식 기사)를 넣었다. `season_memberships.csv`는 펠릭스 행만 다시 계산해 바꿨다(전체 재계산은 11-25 규칙 변경분까지 섞여 따로 한다).
- CD 바스코니아(아틀레틱 위성팀)와 쓰쿠바 대학 축구부는 1군 프로가 아니라 `career_quiz_reserve_teams.csv`로 뺐다.
- 같은 클럽·같은 임대 여부로 겹치는 구간(위키데이터 중복 진술, 지동원의 아우크스부르크 등)은 생성 스크립트가 하나로 합친다.
- 축구 데이터 보정은 별도 PR(#127, 날짜 없는 위키데이터 소속으로 빠졌거나 틀린 선수 182명 경력 조사)로 옮겼다. 이 PR은 그 위에 쌓인다. 그 데이터에서 아르투로 비달의 틀린 우니베르시다드 데 칠레 구간을 지웠고, 마이크 메냥의 PSG 2012~2015(1군 출전 없음)는 퀴즈에서만 `career_quiz_hide.csv`로 가린다.
- 중간에 열린 구간은 대부분 정렬 문제였다(같은 해면 열린 구간이 앞). 같은 해면 닫힌 구간을 먼저 두고, 남은 열린 구간은 생성 스크립트가 닫는다: 임대는 다음 구간 시작, 완전 이적은 다음 완전 이적 시작. 뒤에 임대만 있으면(지금 소속 클럽에서 임대 중) 열어 둔다.

## 5. 답 검색

- 데이터 계층의 DB 검색 RPC `football_search(p_q, 'player', p_lim)`를 쓴다(`20261102062215_football_search.sql`, 승인 사용자만). 한글·영어 별칭과 악센트 무시, 인지도 순 정렬은 이미 되어 있다.
- 자동완성 한 줄에는 이름, 국적, 포지션, 출생 연도가 나온다(RPC가 주는 값. 동명이인 구분용).
- 답은 위키데이터 QID를 보낸다. `logic.apply`가 정답 QID와 비교한다. 서버 판정에는 DB를 쓰지 않는다.
- 후알야 `search.ts`의 두벌식 자판 변환(`deHangul`, 한글 자판으로 친 영문)은 화면에서 RPC를 부르기 전에 쓸지 구현 때 본다.
- **전제**: 운영 DB에 축구 데이터가 적재돼 있어야 한다(`npm run football:load`, 원격 `DATABASE_URL`). 적재 여부는 배포 전에 확인한다.

## 6. 구조

- `scripts/football/build-career-quiz.ts`(`npm run football:career-quiz`)가 `career_quiz.csv`와 `players`·`spells`·`teams`·`manual/*`를 읽어 `src/games/career-quiz/data.ts`를 만든다(후알야 `build-wya-data.py`와 같은 역할, 직접 고치지 않음). 문제마다 QID, 이름(한·영), 난이도, 경력 줄(연도, 클럽 한글 이름, 임대)을 담는다.
- `logic.ts`가 문제를 고르고 판정한다. `play` Edge Function이 번들하므로 데이터나 규칙을 바꾸면 `logic.version`을 올리고 `play`를 다시 배포한다.
- 등록: `src/games/index.ts`, 화면은 `src/games/ui.ts`(`getGameComponent`).
- 마이그레이션: `game_modes` (false, false, true) 행, `hidden_games` 행, 골드 한 줄.
- 숨김(`hidden: true`)으로 먼저 머지하고, 관리자가 확인한 뒤 연다.

## 7. 테스트

- `logic.test.ts`: 모드별 첫 상태, 챌린지에서 가린 줄의 클럽이 `publicState`에 없음, 오답·버튼으로 줄 열기, 8번 제한, 이니셜(3번 전 거절·한 번만), 점수 표.
- 생성 스크립트 테스트: 2·3군·유스 거르기, 끝 연도 채우기.
- 데이터 검사(`data.ts`): 명단 ID가 `players.csv`에 있고, 거른 뒤 경력이 한 줄 이상이며, 경력이 같은 다른 선수가 없다.
- `gold.test.ts`, `registry.test.ts`.
