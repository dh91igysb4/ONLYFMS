# 내 섬 C단계 설계 — 집

작성 2026-11-26. 상위 설계 `2026-11-25-my-island-design.md` §2의 C("텐트 → 오두막 → 집 → 방 추가, 방 안 가구 놓기"). B 설계(`2026-11-26-my-isle-b-design.md`) 위에 쌓는다. 사용자가 맡기고 잠들어 결정 대부분은 **Claude가 정했다**(맨 아래 목록).

## 1. 왜 · 무엇을 느끼게
- 텐트에서 시작해 재료와 골드로 집을 키우고, 들어가서 만든 가구를 놓는다. 친구가 놀러 와 집 안을 구경한다.
- B의 재료(나무·돌·철)를 계속 쓸 곳이 생긴다. 3개월 목표의 두 번째 덩어리.

## 2. 목표 · 비목표 · 실패 조건
**목표**
- 작업대 "집" 탭에서 집 단계를 올린다: 0 텐트 → 1 오두막 → 2 작은 집 → 3 집 → 4 큰 집(최고). 섬의 건물 그림이 단계마다 바뀐다.
- 1단계부터 문으로 들어가면 집 안(새 지역 `home`)이다. 단계가 오를수록 방이 넓어진다(바닥 6×4 → 8×5 → 10×6 → 12×7).
- 작업대 "가구" 탭에서 가구를 만들고(재료 + 약간의 골드), 집 안에서 "놓기"로 앞 칸에 놓고 "치우기"로 다시 가방(가구 보관함)에 넣는다.
- 친구 집에도 들어가 구경한다(놓기·치우기 없음).

**비목표**
- 2층·방 여러 개(단계마다 한 방이 넓어지는 것으로 대신 — 내가 정함), 벽지·바닥 바꾸기, 가구 돌리기, 2칸 이상 가구. 바깥 꾸미기(D).
- 가구 팔기·주기.

**실패 조건**
- 가구로 문이 막히거나 집 안에 갇히는 배치가 저장된다.
- 남이 내 집 가구를 바꾼다. 가구·집으로 골드가 생긴다.
- 옛 세이브(v23)를 읽지 못한다.

## 3. 접근
- **채택: 집 안은 주인별 지역 `home` + 가구 목록을 세이브에(내가 정함).** 섬과 같은 방식(장소 키 `home-<주인 id>`, 남의 집은 `visit`의 `publicView`로). 맵은 (단계, 가구 배치)로 만든 `MapDef`, 가구 칸은 못 걷는 칸.
- 버림: 섬 맵 안에 집을 키워 바깥에서 보기 — 실내 가구가 안 보이고 "들어간다"는 느낌이 없다.
- 버림: 방 여러 개 — 맵·문 연결이 단계마다 바뀌어 C가 커진다.

## 4. 상세
### 4.1 저장 상태 (`State.isle` 안, logic.version +1)
```
house: number                       // 0..4
furniture: Record<FurnId, number>   // 만든 뒤 놓지 않은 개수(0..99)
placed: { id: FurnId; tx: number; ty: number }[]  // 집 안 놓인 가구(칸마다 하나, 최대 40)
```
- migrate: v23 섬은 `house 0, furniture {}, placed []`. 모르는 가구·방 밖·겹침은 버린다(놓인 것은 보관함으로 돌린다).

### 4.2 집 단계 가격 (내가 정함)
- 단계 n(1..4): 골드 `floor10(REF × 1.7 × n^1.8)`, 나무 `30n`, 돌 `20n`, 철 `10(n−1)`. n ≥ 3이면 개간 4구역 이상, n = 4면 8구역 전부.
  - 골드 34,850 / 121,330 / 251,610 / 422,370 → 합 약 830,000(≈ `REF × 40`).
- 가구 10종(나무·돌·철 몇 개 + 골드 500~5,000). 가구 골드 합(종류마다 1개씩) ≈ `REF × 1`. 개수 제한 없음(재료가 제한).
- 검사: 집 골드 총액 `REF × 40` ±15%.

### 4.3 집 안 맵 (`home.ts`, 순수)
- 단계별 방: 벽(`Y`)으로 둘러싼 바닥(`F`), 아래 가운데 문(출구 → 섬 텐트 문 앞). 방 크기 6×4, 8×5, 10×6, 12×7(바닥 칸).
- `homeMap(level, placed)`: 놓인 가구 칸은 못 걷는 칸, 그림은 `props`(칸마다 가구 스프라이트). 같은 값이면 같은 객체.
- 놓기 규칙(서버·화면 같은 함수 `canPlace`): 방 바닥 칸, 비어 있음, 문 칸과 문 바로 위 칸이 아님, 놓은 뒤에도 남은 모든 빈 바닥 칸이 문 위 칸에서 걸어 닿는다.

### 4.4 행동
- `build { level, price }`: level = house + 1 ≤ 4, 재료·골드·개간 조건. 오류 `bad_level`, `need_clear`, `not_enough_mats`, `not_enough_gold`, `price_changed`.
- `makeFurn { id, price }`: 재료·골드 확인, 보관함 +1(최대 99). 오류 `bad_furn`, `furn_full`.
- `place { id, tx, ty }`: house ≥ 1, 보관함 ≥ 1, `canPlace`. 오류 `no_house`, `no_furn`, `bad_spot`, `room_full`(40개).
- `pickUp { tx, ty }`: 그 칸 가구를 보관함으로. 오류 `no_furn_here`.
- 남의 집에서는 화면이 보내지 않고, 서버는 자기 세이브만 바꾼다.

### 4.5 화면
- 섬 건물 그림: 단계마다 스프라이트(`tent`, `hut`, `cottage`, `house`, `manor`). 0단계 텐트 앞 안내는 그대로, 1단계부터 문이 출구.
- 집 안: 문 위 칸에 도착, 아래 문으로 나가면 섬 텐트(집) 문 앞.
- 집 안에서 앞 칸이 빈 바닥이면 행동 버튼 "놓기"(보관함이 비면 비활성 대신 안내), 앞 칸이 가구면 "치우기". "놓기"는 작은 창(보관함 가구 목록)에서 골라 놓는다.
- 작업대 탭 추가: "집"(다음 단계 비용·조건, "짓기"), "가구"(목록, 만든 개수, "만들기").
- 친구 집: `publicView`에 `house`, `placed`를 더한다. 문으로 들어가 구경.
- 기록 `house`(값 = 단계, "집 4/4"). 메인 미리보기 기록 `isle` 값은 `layout:cleared:house`.

## 5. 제약
- B와 같다. 새 지역 `home`(`spots` 없음, `onWorldMap false`, 기본 지역). 장소 키 일반화: `isle-<id>`·`home-<id>`.
- 다른 세션이 낚시 버전을 또 올렸으면 리베이스하며 한 칸 더 올린다.

## 내가 정한 것 (사용자 확인 필요)
1. 방은 하나, 단계마다 넓어진다(방 추가 대신).
2. 집 4단계, 가격 수치(§4.2), 집 골드 총액 `REF × 40`.
3. 가구 10종, 1칸짜리, 돌리기 없음, 방에 최대 40개.
4. 3단계부터 개간 조건(4구역·8구역).
5. 가구 보관함은 가방과 따로(물고기 가방 칸을 쓰지 않는다).
