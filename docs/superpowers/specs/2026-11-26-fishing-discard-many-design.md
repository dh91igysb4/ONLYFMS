# 낚시 여러 마리 한 번에 버리기 (2026-11-26, 작은 변경)

## 왜
한 마리씩 버리면 번거롭다. 여러 마리를 골라 한 번에 버린다. 요청을 마리마다 보내면 초당 요청이 많아져 로그아웃될 수 있으므로(사용자 지적) **요청은 한 번**이어야 한다.

## 결정(사용자 확인)
- 가방 "버리기" 모드와 마을회관 쓰레기통: 물고기를 누르면 선택이 켜지고 꺼진다(잠긴 물고기는 못 고름). 확인 줄 "N마리 버리기 · 환경부담금 합계"(한 마리면 지금처럼 이름·크기), [버리기] 한 번.
- 요금은 지금 규칙(가방 판매가 50%, 쓰레기통 5%, 마리마다 올림, 최소 1)을 마리마다 더한다.
- [잠기지 않은 것 모두 선택]·[선택 해제].
- 서버 새 행동 `discardMany { items: [{ index, species, sizeCm }], fee, at }`: 모두 검사하고 하나라도 틀리면 아무것도 버리지 않는다(bad_action·bag_changed·locked·price_changed·not_enough_gold). `logic.version` 20 → 21, `world` 재배포. 옛 `discard`(한 마리)는 옛 화면을 위해 그대로 둔다.

## 기각
- 화면이 한 마리 버리기를 여러 번 보내기: 재배포는 필요 없지만 요청이 많아 느리고, 로그아웃 위험, 중간 실패 시 일부만 버려짐.
