# 펨타듀 밸리 온라인 2단계-1 — 다른 지역 친구 위치 (큰 지도·메인)

- 날짜: 2026-11-24
- 상태: **승인됨** (2026-11-24)
- 관련: `2026-11-24-fishing-online-design.md`(1단계, 2단계 범위), `2026-11-24-home-valley-design.md`(메인 미리보기), `2026-11-24-fishing-map-design.md`(큰 지도)

## 1. 의도
1단계는 같은 지역에 있어야 친구가 보인다. 다른 지역에 있어도 누가 어디서 무엇을 하는지 알게 해서 같은 세계에 있다는 느낌을 키운다. 2단계 세 덩어리(친구 위치 → 말풍선·채팅·이모트 → 대전 걸기) 중 첫째.

## 2. 목표 / 비목표 / 실패 조건
**목표**
- 메인 미리보기 모서리에 접속 중인 친구 요약: `접속 중 2명 · son 숲에서 낚시 중` (사용자 선택 A).
- 큰 지도(지도 창): 지역 탭마다 그 지역 친구 수, 그 지역 지도 위에 아이디가 달린 점(내 판단).

**비목표**
- 접속 안 한 친구의 마지막 위치(범위 3, 고르지 않음), 친구 위치로 순간이동·길 안내
- 메인만 열어 둔 사람을 "접속 중"으로 세기

**실패 조건**
- 메인을 열 때마다 사용량이 눈에 띄게 늘어난다(메인은 듣기만).
- 실시간 연결이 실패해 메인 미리보기나 지도가 깨진다.
- 나 자신이 목록·점에 나온다.

## 3. 접근 방식 (사용자 확인)
| | 방식 | 판단 |
|---|---|---|
| **A** | **게임 전체 방 `world:<gameId>` 하나, 각자 프레즌스로 상태를 올림** | **선택.** 지역·하는 일이 바뀔 때와 움직이는 동안 10초에 한 번만 갱신, 6명이어도 초당 4개 안팎 |
| B | 메인·지도가 지역 방 10개에 모두 들어감 | 지도 하나에 1단계 위치 메시지를 전부 받음, 한도에 걸림 |
| C | 마지막 위치를 DB에 저장 | 범위 3이라 고르지 않음, 걸을 때마다 DB 쓰기 |

## 4. 설계
### 4.1 방과 상태 (플랫폼 공통, `src/platform/world/presence.ts`)
- 채널 `world:<gameId>`(공개, 프레즌스 키 = 사용자 id). 1단계 지역 방과 별개.
- 올리는 상태: `{ id, handle, area, act: 'walk' | 'fish', tx, ty }` (tx·ty는 칸 좌표).
- 갱신(`track`): 들어갈 때, 지역이 바뀔 때, act가 바뀔 때, 움직이는 동안 10초에 한 번(칸이 바뀐 경우만). 탭이 숨으면 1단계처럼 나간다.
- 메인 화면은 같은 채널에 **듣기만** 한다(`track` 안 함).
- 받은 상태는 1단계와 같은 방식으로 검사(타입·길이), 나 자신은 뺀다.
- 숨김 게임이면 관리자만(1단계와 같음). 연결 실패는 경고만.

### 4.2 메인 미리보기 (사용자 선택 A)
```
┌──────────────────────────┐
│ 접속 중 2명 · son 숲에서 낚시 중 │
│        (내 자리 풍경)          │
│                     들어가기  │
└──────────────────────────┘
```
- `WorldPreviewProps`에 `online: OnlinePeer[]`를 더하고, 문구는 게임 쪽(낚시 `Preview`)이 지역 이름으로 만든다(플랫폼은 지역 이름을 모른다).
- 이름은 최대 2명(가까운 순서 없음, 아이디 가나다순), 넘으면 `외 n명`. 0명이면 표시 없음.
- 문구: 낚시 중이면 `<아이디> <지역>에서 낚시 중`, 아니면 `<아이디> <지역>`.

### 4.3 큰 지도
- 지역 탭 이름 옆에 그 지역 친구 수(0이면 없음).
- 지도 그림 위에 친구 점(내 위치 표시와 구분되는 색) + 아이디 이름표. 위치는 최대 10초 늦다.
- 지도 창을 연 동안 새 상태가 오면 다시 그린다.

### 4.4 사용량
- 6명 모두 밸리에서 움직이는 최악: 각자 10초에 한 번 → 초당 0.6번 × (1 + 받는 사람 최대 5 + 메인만 열어 둔 사람) ≈ 초당 4~6. 1단계 위치 메시지(최대 초당 80)와 합쳐도 한도 100 안.

## 5. 내가 정한 것 (사용자 확인 필요)
- 큰 지도: 탭에 인원 수 + 지도 위 점·아이디.
- 메인만 열어 둔 사람은 접속 중으로 세지 않는다.
- 메인 문구는 최대 2명, 아이디 가나다순.
- 위치 갱신 10초.
