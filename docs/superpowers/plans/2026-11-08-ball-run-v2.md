## Review Focus

1. **기운 판 위에서 손을 뗀 경우**: 공이 계속 아래쪽으로 밀려 결국 떨어질 수 있어야 한다(원작). 단, 기운 판이 끝나면 밀림도 즉시 멈춘다. → Task 2 `bank push stops off the bank`.
2. **단차 착지 직후 정면 판정**: 1 m 단차를 내려간 직후 다음 칸이 같은 높이면 `hit`이 나면 안 된다. → Task 2 `drops down a ledge and lands alive`.
3. **반전된 기운 판**: 좌우 반전 조각에서 `bank` 부호가 반대여야 한다(아니면 반전 조각이 다른 게임이 된다). → Task 3 `mirror flips bank`.
4. **시작 터널**: 첫 조각은 속도 단계를 올리지 않는다(시작 직후 '속도 증가'가 두 번 뜨면 안 된다). → Task 2 `start tunnel does not count`.
5. **카메라가 단차에서 튐**: y 보간이 없으면 단차마다 화면이 덜컹인다. → Task 5 수동 확인 + `cameraTarget` 단위 테스트.
