# 볼 런(ball-run) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 3D 끝없는 러너 '볼 런'을 자유 플레이 점수 게임으로 추가하고, 그에 필요한 게임별 점수 범위를 플랫폼에 넣는다.

**Architecture:** 정수 전용 순수 시뮬(`sim.ts`)과 시드 기반 조각 이어붙이기 코스(`course.ts`)를 `logic.ts`가 감싸 플랫폼 `GameLogic` 계약을 따른다. 화면(`Game.tsx`)은 같은 시뮬을 로컬로 돌려 그리고 입력은 0.5초 묶음으로 플랫폼에 보낸다. Three.js 렌더러는 `render/`에만 있고 동적 import로 별도 청크가 된다.

**Tech Stack:** React 18 + Vite + TypeScript, vitest + Testing Library(jsdom), Supabase Postgres(pgTAP 테스트), Three.js(신규).

**Spec:** `docs/superpowers/specs/2026-11-07-ball-run-design.md` — 각 태스크 전에 해당 절을 읽는다.

## Review Focus

1. **화면 회전·크기 변경 중 플레이**: 캔버스와 렌더러가 새 크기를 따르고, 드래그 매핑은 *현재* 폭을 쓴다. → Task 9 `resizes renderer on window resize`.
2. **두 번째 손가락**: 드래그 중 다른 손가락이 닿아도 첫 포인터만 따른다. → Task 9 `ignores a second pointer while dragging`.
3. **탭 숨김 후 복귀**: 숨김 동안 틱이 없고, 복귀 직후 몰아서 따라잡지 않는다(누산기 초기화). → Task 9 `does not catch up after the tab was hidden`.
4. **긴 프레임 지연**: 한 프레임에 5틱 초과로 돌지 않고, 보내는 행동 하나의 틱 합이 120을 넘지 않는다(넘으면 플랫폼이 거부해 판이 꼬인다). → Task 9 `never sends a batch over 120 ticks`.
5. **판 도중 이탈(언마운트)**: 이후 `onAction` 호출 없음, rAF·리스너·장면 `dispose`. → Task 9 `stops and disposes on unmount`.

### Task 3: 코스 생성기

**Files:**
- Create: `src/games/ball-run/course.ts`, `src/games/ball-run/course.test.ts`

**Interfaces:**
- Consumes: `Cell`, `ParsedSegment`, `PARSED`, `START_PARSED` (Task 2), `TIER_WEIGHTS`, `ROW`.
- Produces:
  ```ts
  export type SegmentInfo = { id: string; tier: 1|2|3|4; startRow: number; length: number; mirrored: boolean; base: number; decor?: 'tunnel' }
  export interface Course {
    readonly seed: string
    cell(col: number, row: number): Cell         // col 범위 밖·row < 0 → { floor: null, block: false }
    segmentAt(row: number): SegmentInfo
    segmentsBetween(fromRow: number, toRow: number): SegmentInfo[]
  }
  export function getCourse(seed: string): Course                     // seed: /^[0-9a-f]{32}$/, 최근 4개 캐시
  export function courseFromSegments(list: { seg: ParsedSegment; mirrored: boolean }[]): Course  // 끝 뒤는 무한 평평 직선(테스트·봇용)
  export function u32Stream(seed: string, salt: string): () => number  // 정수 [0, 2^32) sfc32, salt로 흐름 분리
  export function decorRandom(seed: string): () => number              // u32Stream(seed, 'decor')
  ```
  `cell`의 바닥 높이는 절대값(`base` + 상대), `SegmentInfo.base`는 그 조각 시작 높이.

- [ ] **Step 1: 실패하는 테스트**
  - `same seed same course`: 두 번 `getCourse('0123…'(32자))`의 row 0~3000 `cell` 전부 같음(JSON 비교). 다른 seed는 row 0~3000에서 하나 이상 다름.
  - `starts with START`: `segmentAt(0).id === 'start'`, `startRow === 0`.
  - `no repeat within last 3`: seed 10개 × 조각 200개에서 연속 4개 창 안에 같은 id 없음(`start` 제외).
  - `respects tier schedule`: 각 조각의 시작 거리 m(`startRow`)에서 `TIER_WEIGHTS`상 가중치 0인 tier가 나오지 않음.

  - `heights are continuous at joints`: 조각 경계 행에서 앞 조각 끝 높이 = 다음 조각 `base`.
  - `decor stream is independent`: `decorRandom(seed)`를 1000번 먼저 호출해도 `getCourse(seed)` 결과 동일(새 seed로 캐시 영향 배제).
