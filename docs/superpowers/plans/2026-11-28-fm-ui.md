# 사이트 FM 스타일 개편 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 머리글과 화면 7개(홈·게임·대전·순위·대회·프로필·제안)를 FM24 결로 바꾸고, 나머지 화면은 공통 부품으로 결을 맞춘다.

**Architecture:**
- `theme.css`에 토큰 파생 변수(`--fm-head`, `--fm-line`, `--fm-me`)와 `fm-*` 공통 부품을 덧붙이고, 기존 공통 클래스의 모서리와 그림자를 조인다.
- 화면마다 마크업을 판(`.fm-panel`)·줄(`.fm-row`)·표(`.fm-table`)로 다시 짠다.
- 데이터와 RPC는 지금 그대로 쓴다.

**Tech Stack:** React 18 + TypeScript, Vite, plain CSS, Vitest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-11-28-fm-ui-design.md`

## Global Constraints
- 모든 화면 문구는 한국어, 모바일 우선(390px에서 넘침 없음).
- 색은 `theme.css`·`palettes.ts` 토큰만 쓴다. 파생은 `color-mix(in srgb, var(--a), var(--b) N%)`로만 만든다.
- 플랫폼 코드에 게임 id 분기를 두지 않는다.
- `src/games/**`는 `types.ts`의 `shortName?: string`, `fishing/manifest.ts`의 `shortName: '밸리'` 두 줄만 바꾼다. `supabase/**`와 `Brand.tsx`는 바꾸지 않는다.
- 지금 할 수 있는 동작의 클릭 수를 늘리지 않는다.
- 모서리: 판·버튼·입력 4px, `.card` 6px.
- 글자: 판 제목 띠 11px 굵게, 본문 13–15px, 숫자 16–18px 굵게 `tabular-nums`. 글꼴은 바꾸지 않는다.
- 승·무·패 칸: 테두리형. `--panel` 바탕, 글자·테두리 색은 승 `--win-text`, 패 `--lose-text`, 무 `--muted`. `void` 대국은 뺀다.
- 화면별로 커밋한다. 푸시 전에 `npm test && npm run typecheck && npm run build`를 돌린다.

## Review Focus
1. **라이트 모드 팔레트에서 판 제목 띠·내 줄 바탕 위 글자가 안 보이는 경우.** 20개 조합 모두 대비 4.5 이상이어야 한다. → Task 1 `fm contrast` 시험.
2. **관리자가 아닌 사람의 계정 메뉴.** "관리자" 항목이 없어야 하고, 관리자는 결정 대기 배지 숫자를 메뉴 버튼에서도 볼 수 있어야 한다. → Task 2 시험.
3. **지속형 게임이 숨김이거나 없는 경우의 밸리 버튼.** 일반 사용자에게는 버튼이 없어야 하고, 관리자에게는 숨김 게임도 보여야 한다(HomePage 규칙과 같음). → Task 2 시험.
4. **홈의 판 하나가 실패할 때.** 그 판만 "불러오지 못했어요"가 뜨고 나머지 판과 밸리 미리보기는 그대로여야 한다. → Task 3 시험.
5. **내가 오늘 순위 4위 밖이거나 기록이 없을 때.** 4위 밖이면 위 3명 + 구분 + 내 줄을, 기록이 없으면 위 3명만 보여 준다. → Task 3 시험.
